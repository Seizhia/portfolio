# Jefferson Inog — Portfolio

A black-dominant, responsive portfolio with restrained red accents for a BS Information Systems student. Its architectural composition, oversized typography, dotted geometry, and navigation dock take inspiration from roomandpillar.com. All content and rendered artwork are original. Built with HTML, CSS, and JavaScript; no build tools or installation required.

Open `index.html` in a modern browser to view it. Keep `style.css` and `script.js` in the same folder.

## Features

- Animated dotted 3D architectural blocks rendered with the Canvas API. Drag to rotate, use arrow keys while focused, or pause the animation.
- Interactive bubble-sort, stack, and color demos.
- Mobile layouts, scroll reveals, an active navigation dock, keyboard controls, native accessible dialogs, and reduced-motion support.
- Google Fonts with local system fallbacks. The page and demos also work without a font connection.

## Personalization

The biography and learning interests use the supplied details. The playground contains demonstrations, rather than claims of completed personal projects. School, email, and social profiles were not supplied. Contact details are explicitly marked as coming soon.

Edit the biography and project descriptions in `index.html`, styling in `style.css`, and interactions in `script.js`. To add a contact destination, replace the contact button and its dialog handler with your email or social link.

## Verification

Checked HTML parsing, unique element IDs, section anchor targets, and local stylesheet/script references. Browser checks and screenshots use the installed Chrome at desktop and mobile viewport sizes; verification artifacts live in `.preview/`. Hosted publication was not completed because the Sites workflow requires Node.js and Git, which are unavailable here.
